# 概要设计说明

> 历史单体概要：当前 BFF + 4 业务微服务架构见 [`architecture/microservices-inventory.md`](architecture/microservices-inventory.md) 和 [`diagrams/final/current-architecture.mmd`](diagrams/final/current-architecture.mmd)。

## 架构

```text
React/Vite 前端
  -> Spring Boot REST API
    -> Controller
      -> DemoStore Service
        -> 内存数据集合
```

后续持久化版本将 `DemoStore` 拆分为 `Service -> Mapper -> Database`，保持 Controller API 不变。

## 鉴权

- `/api/v1/auth/login`、商家浏览、分类公开。
- 用户订单、购物车、评价需要登录。
- `/api/v1/merchant-admin/**` 需要 `MERCHANT_ADMIN`。
- `/api/v1/admin/**` 需要 `PLATFORM_ADMIN`。

## 状态机

外卖订单：

```text
PENDING_PAYMENT -> PAID -> ACCEPTED -> DELIVERING -> COMPLETED
```

团购订单：

```text
PENDING_PAYMENT -> PAID -> USED
```
