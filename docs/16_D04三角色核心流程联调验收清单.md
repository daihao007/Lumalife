# D04 用户、商家与管理员核心流程联调验收清单

> 任务：`[D04][B][2026-08-28] 完成用户、商家与管理员核心流程联调`

## 联调结论

- 用户消费链路：登录、发现商家、详情加购、购物车下单、支付、确认收货与评价均有稳定路由和关键操作选择器；详情加购/团购购买、购物车及订单操作均具备提交中和失败反馈。
- 商家处理链路：外卖订单支持接单、开始配送、完成；团购订单不显示外卖履约按钮，只能通过 12 位券码核销；请求失败后恢复操作并展示业务错误。
- 管理员观测链路：平台管理员可查看 KPI、订单分布、营收趋势、商家排行、活跃订单、账户、健康和日志；加载失败显示中文原因并支持原地重试。
- 角色边界：游客受保护入口跳转登录，三类登录角色只能进入各自页面；后端 USER、MERCHANT_ADMIN、PLATFORM_ADMIN 权限由 API 集成测试兜底。

## 代表性浏览器路径

| 编号 | 角色 | 操作路径 | 可验证结果 |
| --- | --- | --- | --- |
| D04-B-01 | 用户 | `#/login -> #/discover -> #/merchants/{id} -> #/cart -> #/orders` | 加购、按商家拆单、支付、状态时间线、收货和评价连续可完成 |
| D04-B-02 | 用户/商家 | 用户购买团购并支付；商家进入 `#/merchant/orders` 输入券码 | 用户看到 12 位券码；商家核销为 USED；团购不出现外卖履约按钮 |
| D04-B-03 | 商家 | `#/merchant/orders` 依次处理 PAID、ACCEPTED、DELIVERING 外卖订单 | 按钮依次显示接单、开始配送、完成订单，非法重复操作显示错误 |
| D04-B-04 | 平台管理员 | `#/login -> #/admin` | 看板数据正常展示；接口失败时显示中文错误，点击重新加载后可恢复 |
| D04-B-05 | 越权角色 | 手工访问其他角色 Hash 路由或直接请求受保护 API | 前端返回本角色工作台，后端返回 401/403 |
