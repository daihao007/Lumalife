# 核心需求说明

| ID | 名称 | 当前实现 |
|---|---|---|
| CR-01 | 用户认证与个人中心 | 演示账号登录、Token 鉴权、角色区分、收货地址管理 |
| CR-02 | 商家搜索、分类、推荐与详情 | 分类入口、关键词搜索、评分+距离排序、详情商品/团购/评价 |
| CR-03 | 购物车、下单、模拟支付、订单跟踪 | 跨商家购物车、按商家拆单、数量修改、删除/清空、创建外卖订单、待支付取消、支付幂等、订单状态时间线 |
| CR-04 | 团购购买、券码生成、商家核销 | 团购下单、支付生成 12 位券码、商家核销 |
| CR-05 | 评价与评分统计 | 完成/已使用订单可评价、一单一评、更新商家评分 |
| CR-06 | 商家后台 | 订单履约、状态流转、团购券核销、商品维护、团购套餐维护 |

验收重点：

- 非法状态流转返回业务冲突。
- 支付使用 `clientRequestId` 保证幂等。
- 待支付订单可由用户取消，已支付订单不可直接取消。
- 商家只能处理自己店铺订单和券码。
- 平台管理员才能访问平台看板。
