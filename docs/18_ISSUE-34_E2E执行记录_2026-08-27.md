# Issue #34：CR-01～CR-06 核心用例 E2E 执行记录

## 1. 任务与范围

| 项目 | 内容 |
| --- | --- |
| 任务 | [Issue #34](https://github.com/daihao007/Lumalife/issues/34) |
| 负责人 | `ZQHtech` |
| 分支 | `codex/d04-core-e2e` |
| E2E 方式 | 独立 Node.js 真实 HTTP 黑盒运行器，不依赖 Spring MockMvc |
| 排除范围 | 骑手/配送员模块不属于已冻结的 CR-01～CR-06 范围 |
| 报告 | `e2e/reports/e2e-report.json`、`e2e/reports/e2e-report.xml`、`e2e/reports/e2e-summary.md`、`e2e/reports/e2e-raw.log`（脱敏摘要） |

运行器默认在 `18080` 启动隔离临时后端，传入空状态文件并在结束后清理进程；不会复用已有后端，因此库存、订单和账号状态不会污染下一次运行。只有显式设置 `E2E_START_BACKEND=0` 时才连接外部服务。

## 2. 执行命令与环境

```powershell
cd e2e
npm test
```

环境启动失败也会写入统一诊断报告：JSON 记录环境错误和脱敏请求摘要，JUnit XML 使用 error 节点，Markdown 提供审核摘要，进程以非零状态退出以阻断 CI。

## 3. 覆盖矩阵

| 用例 | 成功流程 | 权限边界 | 异常流程 | E2E 场景 |
| --- | --- | --- | --- | --- |
| CR-01 用户认证与个人中心 | 注册→查询当前用户→更新资料→新增/设置默认地址 | 商家不能访问用户地址；匿名不能访问购物车 | 角色不符、未认证访问 | `CR-01 用户认证、资料与地址管理` |
| CR-02 商家搜索、分类、推荐与详情 | 分类→关键词筛选/排序→个性化推荐→商家详情 | 游客可浏览公开目录 | 不存在商家返回 404 | `CR-02 分类搜索、推荐与商家详情` |
| CR-03 购物车、下单、支付与跟踪 | 加购→改数量→地址下单→支付→订单查询 | 商家不能读取用户订单 | 已支付订单不可取消；支付幂等重试 | `CR-03 购物车、下单、支付与订单跟踪` |
| CR-04 团购购买与券码核销 | 团购下单→支付→生成券码→所属商家核销 | 其他商家不能核销 | 数量为 0、未知券码、重复核销 | `CR-04 团购购买、券码核销与异常边界` |
| CR-05 订单评价与评分 | 完成外卖订单→收货→评价→商家查看 | 评价必须属于当前用户订单 | 评分超范围、重复评价 | `CR-05 完成订单评价、评分校验与重复评价限制` |
| CR-06 商家后台履约 | 商家接单→配送→完成；平台查看指标 | 普通用户不能访问商家后台；其他商家不能履约 | 非法状态、非法商品/套餐价格库存 | `CR-06 商家履约、商品/套餐校验与角色边界` |

## 4. 验证记录
