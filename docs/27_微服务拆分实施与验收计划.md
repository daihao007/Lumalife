# 微服务拆分实施与验收计划

## 1. 目标

把当前“单体网关承载业务 + 三个服务骨架”的过渡架构收敛为可独立构建、独立健康检查、独立持久化和可按边界回滚的三服务架构。网关继续对外提供稳定的 `/api/v1` 契约，前端不感知服务地址。

## 2. 边界与数据所有权

| 服务 | 负责能力 | 主要持久化数据 |
| --- | --- | --- |
| identity-service | 登录、注册、会话、用户资料、头像、地址 | `user_account`、`auth_session`、`user_address` |
| merchant-service | 分类、商家、商品、团购、收藏、客服会话 | `category`、`merchant`、`product`、`merchant_catalog`、`group_deal`、`merchant_favorite`、`chat_message` |
| order-service | 购物车、下单、订单、支付、履约、券码、评价 | `order_main`、`order_item`、`order_status_timeline`、`payment_record`、`coupon`、`review`、`service_cart_item` |

跨服务只通过 HTTP 内部契约传递 ID、查询结果或不可变快照；网关兼容适配器不得直接访问另一服务的数据表。

当前部署先在同一 MySQL 实例内按服务表集合隔离所有权，保留独立数据库连接配置。后续迁移到独立 schema/数据库不改变网关和服务 HTTP 契约。

## 3. 实施批次

### 批次 A：数据与服务持久化

- 身份服务从本地 JSON 切换到 MySQL，会话只保存 SHA-256 token hash。
- 头像字段升级到 `MEDIUMTEXT`，限制前后端均为 2 MB。
- 商家服务优先读取 `merchant_catalog`，未执行回填时兼容读取 `product`，并补齐商品名搜索、排序和筛选。
- 订单服务使用富订单模型写入订单主表、明细、时间线和支付记录。
- 启动时把旧 `order_record` 迁移成富订单，订单号从数据库最大值继续递增。

### 批次 B：网关切流

- 三组迁移开关默认开启，身份、目录、收藏/客服、购物车、订单和支付链路进入对应服务。
- 远程 DTO 保留 `merchantName`、`type`、`lines`、`addressSnapshot`、`statusTimeline` 等前端字段。
- 订单支付只允许 `PENDING_PAYMENT`，同一用户的 `clientRequestId` 跨订单冲突，重复请求返回同一成功结果。
- 商家详情评价由 order-service 的只读投影接口提供。

### 批次 C：部署与验证

- Compose/Kubernetes 给身份服务注入 MySQL 配置并启用 `prod` profile。
- 初始化清单纳入 V007，CI 检查七个版本迁移和头像存储类型。
- 每个服务提供统一的 health/liveness/readiness/info 入口。
- 保留按服务关闭远程开关的单边界回滚能力。

## 4. 验收标准

1. 重启任一服务后，用户会话、头像、商品、客服消息、购物车和订单仍可读取。
2. 搜索商家名和商品名均能命中；价格、评分、销量、距离排序产生不同顺序；筛选条件有效。
3. 新订单 ID 大于数据库已有最大 ID；取消订单支付返回冲突且订单状态不变。
4. 支付成功后订单查询仍为 `PAID`，重复支付不生成第二笔支付记录。
5. 订单详情显示真实商家名、商品明细和地址快照，不显示“未知商家”。
6. 四个演示商家的商品和团购数据均能从服务返回，商家 AI 无外部 key 时返回本地降级答案。
7. `mvn -B -ntp -f services/pom.xml verify`、后端 Maven 测试、前端测试和构建通过；数据库 verify、Compose smoke、API/UI E2E 在目标环境通过。

## 5. 部署顺序

```bash
docker compose --profile db-tools run --rm db-seed
docker compose --profile db-tools run --rm db-backfill-services
docker compose up --detach --build --wait
```

生产环境先执行数据库迁移和回填，再发布三个服务，最后发布网关。出现单服务异常时只关闭对应的 `LUMALIFE_<SERVICE>_REMOTE_ENABLED` 与 `...BACKFILL_COMPLETED`，不回滚其他边界。
