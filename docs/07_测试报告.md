frontend -> backend BFF -> identity / merchant / order / assistant

### 3.2 UI E2E 修复结论

客服流程原先复用可变种子用户，并把始终可见的首页导航当作注册完成信号，造成用户状态污染和注册路由竞态。修复后：

1. 每次场景注册唯一用户；
2. 等待确定的 `#/profile` 成功路由；
3. 返回首页后按唯一昵称定位客服会话；
4. 完整 Playwright 套件连续两次均为 3/3，通过时间分别为 12.4 秒和 11.1 秒。

新增的 3 个 Spring API case 补齐地址设默认、收藏增删、购物车删除/清空、商家目录读取/删除、用户与商家客服往返、公共助手等直接覆盖缺口。

52/52 只证明每个公开映射至少有一条直接 HTTP 断言，不代表所有参数组合、权限组合和异常分支均已穷举。详细 HTTP 方法、路径、Controller 和测试方法见 `testing/public-api-coverage-matrix.md`。
