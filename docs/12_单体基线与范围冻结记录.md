## 4. `monolith-start` 标签条件

`monolith-start` 是不可变的单体**代码**基线。当前远端标签指向提交 `a1a9352`；从该提交到当前 `main` 的差异仅为三份设计文档，`backend/`、`frontend/` 和 `docker-compose.yml` 均无变化。因此保留该标签，不移动、不覆盖，也不另建替代标签。

本任务在以下条件全部满足后，将该标签作为已确认的单体代码基线记录：

1. `mvn test` 为 40/40 通过，`npm run build` 通过；
2. 后端健康检查为 `UP`，前端根页面可访问；
3. 本表 CR-01～CR-06 均有“通过”或明确的失败/风险记录，不能留空；
4. 本记录、需求跟踪矩阵和测试报告中的范围一致；
5. 关联 PR 已由非提交者完成审查，并在 Issue #16 回填 PR、提交、标签和看板截图链接。
