## 5 本次新增测试与修复

### 5.1 权限修复

在 `SecurityConfig` 中将普通用户业务接口从“任意已认证用户可访问”收紧为 `USER` 角色可访问：

| 接口范围 | 角色要求 |
|---|---|
| `/api/v1/cart/**` | `USER` |
| `/api/v1/orders/**` | `USER` |
| `/api/v1/payments` | `USER` |
| `/api/v1/user/**` | `USER` |
| `/api/v1/reviews` | `USER` |
| `/api/v1/conversations/**` | `USER` |

新增测试 `userOnlyApisRejectMerchantAndPlatformAdminTokens` 验证商家管理员和平台管理员无法访问普通用户购物车、订单和地址接口。

### 5.2 新增 API 集成/端到端测试

| 测试方法 | 覆盖需求 | 覆盖内容 |
|---|---|---|
| `userDeliveryOrderApiCoversCartPaymentMerchantWorkflowAndReview` | CR-03、CR-05、CR-06 | 用户加购、购物车明细、创建外卖订单、模拟支付、商家接单/配送/完成、用户收货、评价、商家查看评价。 |
| `groupBuyApiGeneratesCouponAndMerchantVerifiesOnlyOnceForOwnStore` | CR-04、CR-06 | 团购下单、支付生成 12 位券码、所属商家核销、重复核销拒绝、非本店商家核销拒绝。 |
| `merchantAdminCanMaintainProductAndGroupDealThroughApi` | CR-06 | 商家新增商品、商品上下架、非法商品拒绝、新增团购套餐、套餐启停。 |
| `userOnlyApisRejectMerchantAndPlatformAdminTokens` | CR-01、CR-03、CR-06 | 普通用户接口角色边界，防止商家/平台管理员越权访问用户侧资源。 |

### 5.3 新增业务规则单元测试

| 测试方法 | 覆盖需求 | 覆盖内容 |
|---|---|---|
| `paidGroupOrderGeneratesTwelveDigitCouponCodeAndCanBeVerifiedOnce` | CR-04、CR-06 | 团购支付后生成 12 位数字券码、核销后状态为 `USED`、重复核销被拒绝。 |
| `merchantCannotVerifyCouponFromAnotherStore` | CR-04、CR-06 | 商家不能核销其他店铺的团购券。 |
