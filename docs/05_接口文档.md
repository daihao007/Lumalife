# 接口文档

统一响应：

```json
{ "code": 200, "message": "success", "data": {} }
```

主要接口：

| Method | Endpoint | Auth | 说明 |
|---|---|---|---|
| POST | `/api/v1/auth/login` | Public | 登录 |
| GET | `/api/v1/auth/me` | Token | 当前用户 |
| GET | `/api/v1/categories` | Public | 分类 |
| GET | `/api/v1/merchants` | Public | 商家分页搜索 |
| GET | `/api/v1/merchants/{id}` | Public | 商家详情 |
| GET | `/api/v1/cart/detail` | USER | 购物车明细 |
| POST | `/api/v1/cart/items` | USER | 加购 |
| POST | `/api/v1/cart/items/{productId}` | USER | 修改购物车商品数量，数量小于等于 0 时移除 |
| POST | `/api/v1/cart/items/{productId}/delete` | USER | 删除购物车商品 |
| POST | `/api/v1/cart/clear` | USER | 清空购物车 |
| POST | `/api/v1/orders/delivery` | USER | 创建外卖订单 |
| POST | `/api/v1/orders/group-buy` | USER | 创建团购订单 |
| POST | `/api/v1/orders/{id}/cancel` | USER | 取消待支付订单 |
| POST | `/api/v1/payments` | USER | 模拟支付 |
| GET | `/api/v1/orders` | USER | 用户订单 |
| POST | `/api/v1/reviews` | USER | 提交评价 |
| GET | `/api/v1/user/addresses` | USER | 用户地址列表 |
| POST | `/api/v1/user/addresses` | USER | 新增/编辑地址 |
| POST | `/api/v1/user/addresses/{id}/default` | USER | 设置默认地址 |
| POST | `/api/v1/user/addresses/{id}/delete` | USER | 删除地址 |
| GET | `/api/v1/merchant-admin/orders` | MERCHANT_ADMIN | 商家订单 |
| POST | `/api/v1/merchant-admin/orders/{id}/transition` | MERCHANT_ADMIN | 订单履约流转 |
| POST | `/api/v1/merchant-admin/coupons/verify` | MERCHANT_ADMIN | 团购券核销 |
| GET | `/api/v1/merchant-admin/products` | MERCHANT_ADMIN | 商家商品列表 |
| POST | `/api/v1/merchant-admin/products` | MERCHANT_ADMIN | 新增/编辑商品 |
| POST | `/api/v1/merchant-admin/products/{id}/toggle` | MERCHANT_ADMIN | 商品上下架 |
| GET | `/api/v1/merchant-admin/group-deals` | MERCHANT_ADMIN | 商家团购套餐列表 |
| POST | `/api/v1/merchant-admin/group-deals` | MERCHANT_ADMIN | 新增/编辑团购套餐 |
| POST | `/api/v1/merchant-admin/group-deals/{id}/toggle` | MERCHANT_ADMIN | 团购套餐上下架 |
| GET | `/api/v1/admin/metrics` | PLATFORM_ADMIN | 平台看板 |
| POST | `/api/v1/assistant/ask` | Token | 规则客服 |
