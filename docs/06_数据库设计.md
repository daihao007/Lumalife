# 数据库设计

> 三服务目标 Schema、唯一写入者、跨服务副本和禁止项见
> [`16_三服务接口数据归属与契约草案.md`](./16_三服务接口数据归属与契约草案.md#5-数据和-schema-归属)。
> 本页只描述当前单体的早期持久化建议，不代表已经创建这些表。

当前版本使用内存数据。后续 MySQL 建议表：

- `user_account`
- `user_address`
- `merchant`
- `category`
- `product`
- `group_deal`
- `cart_item`
- `order_main`
- `order_item`
- `payment_record`
- `coupon`
- `review`
- `operation_log`

金额字段统一使用 `BIGINT`，单位为分。订单、支付、券码、评价表均保留 `created_at`、`updated_at` 和 `is_deleted`。

支付幂等索引：

```sql
UNIQUE KEY uk_payment_request (user_id, order_id, client_request_id)
```
