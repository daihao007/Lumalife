# LumaLife 部署文档

## 1 引言

### 1.1 编写目的

本文档用于说明 LumaLife 综合生活助手平台的本地开发部署、生产打包部署、Docker Compose 部署、环境变量配置和常见故障处理步骤，帮助开发人员和验收人员稳定启动系统。

### 1.2 项目概述

LumaLife 采用前后端分离架构：

| 子系统 | 技术栈 | 默认端口 |
|---|---|---|
| 前端 | React 18、TypeScript、Vite、Lucide React、Recharts | `5173` |
| 后端 | Java 17+、Spring Boot 3.3.5、Spring Security、Spring Actuator、Springdoc OpenAPI | `8080` |
| 预留数据库 | MySQL 8.4 | `3306` |
| 预留缓存 | Redis 7 | `6379` |

当前演示版本后端可独立运行，业务数据以内存和本地状态文件为主；Docker Compose 中保留 MySQL 和 Redis 服务，便于后续迁移到持久化实现。

### 1.3 预期读者

本文档适用于项目开发人员、测试人员、课程验收人员和需要部署演示环境的系统维护人员。

## 2 系统部署要求

### 2.1 硬件要求

| 场景 | CPU | 内存 | 磁盘 | 说明 |
|---|---|---|---|---|
| 本地开发 | 2 核及以上 | 4 GB 及以上 | 2 GB 可用空间 | 可运行前后端开发服务 |
| 演示部署 | 2 核及以上 | 4 GB 及以上 | 5 GB 可用空间 | 推荐用于课堂演示 |
| Docker 部署 | 4 核及以上 | 8 GB 及以上 | 10 GB 可用空间 | 同时运行前端、后端、MySQL、Redis |

### 2.2 软件要求

| 软件 | 推荐版本 | 用途 |
|---|---|---|
| JDK | 17 或更高 | 编译和运行 Spring Boot 后端 |
| Maven | 3.8 或更高 | 后端依赖管理和打包 |
| Node.js | 18 或更高 | 前端依赖安装和构建 |
| npm | 8 或更高 | 前端脚本执行 |
| Docker Desktop | 24 或更高 | 容器化部署 |
| Git | 2.40 或更高 | 获取源码 |

### 2.3 端口要求

部署前请确保以下端口未被占用：

| 端口 | 服务 |
|---|---|
| `5173` | Vite 开发服务或 Docker 前端服务 |
| `8080` | Spring Boot 后端 |
| `3306` | MySQL 容器 |
| `6379` | Redis 容器 |

Windows PowerShell 可使用以下命令检查端口：

```powershell
Get-NetTCPConnection -LocalPort 5173,8080,3306,6379 -ErrorAction SilentlyContinue
```

## 4 本地开发部署

### 4.1 启动后端

推荐先尝试 Maven 开发方式：

```bash
cd backend
mvn spring-boot:run
```

如果本机 Maven 插件运行时未正确带入 Spring Boot 运行时依赖，可改用打包后运行：

```bash
cd backend
mvn -DskipTests package
java -jar target/lumalife-backend-0.1.0.jar
```

后端启动成功后，访问：

```text
http://localhost:8080/actuator/health
```

预期返回：

```json
{"status":"UP"}
```

### 4.2 启动前端

```bash
cd frontend
npm install
npm run dev
```

Windows PowerShell 如遇到 `npm.ps1 cannot be loaded`，可使用：

```powershell
npm.cmd run dev
```

前端启动成功后访问：

```text
http://localhost:5173/
```

### 4.3 前端代理配置

开发环境下，`frontend/vite.config.ts` 将 `/api` 和 `/actuator` 代理到后端：

```text
VITE_API_TARGET=http://localhost:8080
```

如需修改后端地址，可在启动前设置环境变量：

```powershell
$env:VITE_API_TARGET="http://localhost:8080"
npm.cmd run dev
```

## 5 生产打包部署

### 5.1 后端打包

```bash
cd backend
mvn clean package -DskipTests
```

生成文件：

```text
backend/target/lumalife-backend-0.1.0.jar
```

运行命令：

```bash
java -jar target/lumalife-backend-0.1.0.jar
```

Linux 服务器可使用：

```bash
nohup java -jar lumalife-backend-0.1.0.jar > backend.log 2>&1 &
```

### 5.2 前端打包

```bash
cd frontend
npm install
npm run build
```

生成目录：

```text
frontend/dist/
```

可将 `dist` 目录交给 Nginx、静态文件服务器或前端容器托管。

### 5.3 Nginx 示例配置

以下配置适用于将前端静态资源和后端 API 部署在同一域名下：

```nginx
server {
    listen 80;
    server_name localhost;

    root /opt/lumalife/frontend/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8080/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    location /actuator/ {
        proxy_pass http://127.0.0.1:8080/actuator/;
    }
}
```

## 6 Docker Compose 部署

### 6.1 启动容器

在项目根目录执行：

```bash
cp .env.example .env
# 编辑 .env，为数据库账号设置随机强密码
docker compose up -d --build --wait
```

空数据卷会自动应用基线 Schema。仅本地演示/测试环境需要数据库样例数据时，执行 `docker compose --profile db-tools run --rm db-seed`。

### 6.2 服务说明

| 服务 | 镜像/构建 | 端口映射 | 说明 |
|---|---|---|---|
| `mysql` | `mysql:8.4` | `${MYSQL_PORT:-3306}:3306` | 自动初始化 Schema 的 MySQL 与持久化卷 |
| `backend` | `./backend` | `8080:8080` | Spring Boot API |
| `frontend` | `./frontend` | `5173:80` | Nginx 前端静态服务与 API 反向代理 |
| `db-migrate` | `mysql:8.4` | 无 | `db-tools` Profile 下执行版本迁移 |
| `db-seed` / `db-clean` / `db-verify` | `mysql:8.4` | 无 | `db-tools` Profile 下的显式数据生命周期工具，不随常规启动 |

### 6.3 停止容器

```bash
docker compose down
```

如需同时清理卷和网络：

```bash
docker compose down -v
```

## 7 环境变量配置

### 7.1 后端环境变量

| 变量名 | 默认值 | 说明 |
|---|---|---|
| `SPRING_PROFILES_ACTIVE` | `prod` | Docker Compose 中默认使用 |
| `AGNES_API_KEY` | 空 | Agnes AI 客服接口密钥 |
| `MYSQL_ROOT_PASSWORD` | 无，必填 | MySQL root 密码；通过 `.env` 或部署密钥注入 |
| `MYSQL_DATABASE` | `life_assistant` | MySQL 数据库名 |
| `MYSQL_USER` | 无，必填 | MySQL 应用/迁移用户名 |
| `MYSQL_PASSWORD` | 无，必填 | MySQL 用户密码；通过 `.env` 或部署密钥注入 |
| `MYSQL_PORT` | `3306` | MySQL 主机端口 |

### 7.2 AI 客服密钥

如需启用真实 Agnes 模型回复，需要在启动后端前设置：

```powershell
$env:AGNES_API_KEY="你的密钥"
java -jar target/lumalife-backend-0.1.0.jar
```

未设置密钥时，系统会使用本地兜底回复，不影响其他业务流程。

### 7.3 前端环境变量

| 变量名 | 默认值 | 说明 |
|---|---|---|
| `VITE_API_TARGET` | `http://localhost:8080` | Vite 开发代理目标 |

## 8 部署验证

```bash
curl http://localhost:8080/actuator/health
```

```json
{"status":"UP"}
```

浏览器访问：

```text
http://localhost:5173/
```

页面应显示 LumaLife 侧边导航和发现页内容。

使用普通用户账号登录：

```text

密码：abc123456
```

登录成功后应能进入发现页，并能访问购物车、订单、收藏、地址和客服功能。

```

返回数据中应包含商家列表和统一响应结构：

```

## 9 常见故障处理

### 9.1 端口被占用

Windows 下可查询端口占用进程：

```powershell
Get-NetTCPConnection -LocalPort 8080,5173 -ErrorAction SilentlyContinue
```

根据 `OwningProcess` 停止对应进程：

```powershell
Stop-Process -Id 进程ID -Force
```

### 9.2 `mvn spring-boot:run` 启动失败

若出现 `NoClassDefFoundError: org/springframework/boot/SpringApplication`，可改用：

```bash
mvn -DskipTests package
java -jar target/lumalife-backend-0.1.0.jar
```

### 9.3 PowerShell 禁止执行 npm 脚本

如遇到 `npm.ps1 cannot be loaded because running scripts is disabled`，使用：

```powershell
npm.cmd run dev
npm.cmd run build
```

### 9.4 前端请求后端失败

请检查：

1. 后端是否监听 `8080`。
2. `VITE_API_TARGET` 是否指向正确后端。
3. 浏览器控制台是否存在 401、403 或代理连接错误。

### 9.5 AI 回复不可用

请检查：

1. 是否设置 `AGNES_API_KEY`。
2. 设置密钥后是否重启后端。
3. 外部网络是否能访问 Agnes 接口。
