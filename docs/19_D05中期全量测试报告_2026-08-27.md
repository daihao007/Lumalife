## 3. 失败注入与报告

使用不可用地址执行外部服务模式：

```powershell
$env:E2E_START_BACKEND = "0"
$env:E2E_BASE_URL = "http://127.0.0.1:65530"
$env:E2E_TIMEOUT_MS = "500"
npm.cmd --prefix e2e test
```

实际结果为环境启动失败、进程退出码 `1`，并生成 `e2e-report.json`、`e2e-report.xml`、`e2e-summary.md`、`e2e-raw.log` 四份报告；该失败属于预期的环境故障阻断，不是业务断言失败。详细记录见 [D05 失败注入记录](evidence/D05/issue-39-failure-injection.md)。

成功运行产生的报告和脱敏原始日志由 CI 上传至 [api-e2e-reports 构建产物](https://github.com/daihao007/Lumalife/actions/runs/33033226839/artifacts/9631024357)；完整流水线见 [Actions Run #33033226839](https://github.com/daihao007/Lumalife/actions/runs/33033226839)。
