## 2. E2E 运行方式

```powershell
cd e2e
npm test
```

运行器先探测 `/actuator/health`，已有后端则复用，否则通过 `mvn spring-boot:run` 启动临时服务，并传入空状态文件，使每次运行从种子数据开始。测试用户使用本次运行生成的唯一账号，避免持久化数据污染后续执行。

可通过 `E2E_BASE_URL`、`E2E_START_BACKEND`、`E2E_TIMEOUT_MS` 和 `E2E_REPORT_DIR` 配置地址、后端启动策略、超时和报告目录。
