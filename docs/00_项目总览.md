# LumaLife 项目总览

> 历史单体总览：正文未完整反映当前 `prod,remote`。答辩当前事实请使用 [`project-facts.md`](project-facts.md)；本文不再作为服务、数据库、API 或测试数字来源。

LumaLife 是一个课程验收导向的综合生活助手平台，目标不是完整商业系统，而是稳定展示本地生活服务的三条核心闭环：

- 用户消费闭环：登录、搜索商家、查看详情、加购、下单、支付、查看订单、评价。
- 商家履约闭环：商家登录、查看订单、接单、配送、完成、核销团购券。
- 平台观测闭环：管理员查看用户数、商家数、订单量、交易额、健康状态和操作日志。

当前代码采用“可运行演示优先”的策略：后端业务数据暂存在内存中，接口契约和模块边界按后续 MySQL/MyBatis-Plus 迁移设计。
